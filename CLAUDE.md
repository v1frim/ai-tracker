# AI Progress Tracker — контекст проєкту

> **Спершу прочитай `HANDOFF.md`** — там актуальний стан, механіки, підводні камені й незакрите.
> Цей файл — лише короткий вступ і правила роботи.

## Що це
Веб-застосунок для відстеження прогресу Вови у вивченні AI-інструментів та заробітку з AI.
Гейміфікація: XP, рівні (100-й = 1 000 000 XP), ліги, стріки, досягнення.

**Квести** — спільна назва для елементів вкладки «Цілі & проєкти»: **цілі / проєкти / плани / задачі** (4-рівнева ієрархія).

Живий сайт: https://v1frim.github.io/ai-tracker/
Репо: https://github.com/v1frim/ai-tracker

## Стек
- React 18 + Vite 5, inline styles, без UI-бібліотек
- Весь застосунок — `src/AITracker.jsx`; константи (інструменти, ачівки, активності, XP-правила) — `src/constants.js`
- Дані — у localStorage (ключ `ai_tracker_v1`) + авто-копія у файл на диску
- Хостинг — GitHub Pages (гілка `gh-pages`)

## ⚠️ Деплой — читай обов'язково
Push до `main` **або будь-якої `claude/**` гілки** → GitHub Actions одразу білдить і **перезаписує живий сайт** (`.github/workflows/deploy.yml`).

Тому:
- **Завжди працюй від актуального `main`** (`git fetch && git checkout -b <гілка> origin/main`). Пуш зі старої бази відкочує сайт і ламає дані Вови — так уже було двічі (11.07 і 30.10.2026).
- Стара збірка ще й перезаписує localStorage без невідомих їй полів → втрачаються дані (інбокс ідей, радіо) і повторно видаються хибні ачівки.
- **Завжди `npm run build` перед пушем.** Якщо `vite: not found` — `npm install`.
